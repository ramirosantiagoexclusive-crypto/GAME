# 🎮 MMO Survival — MOBA-стиль управление

## ✅ Готово к тестированию!

Полностью рабочий прототип с **MOBA-стилем управления** (как в Mobile Legends / League of Legends).

## 🚀 Как запустить

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## 🎮 Управление (MOBA-стиль)

### 💻 Для ПК

**Движение:**
- **ЛКМ по земле** — персонаж идёт к точке (move-to-click)
- **ПКМ** — альтернативное движение (как в LoL/Dota)
- **WASD / Стрелки** — прямое управление движением
- **S** — стоп (отменить движение)

**Атака:**
- **ЛКМ по NPC** — выбрать цель и автоатака
- Персонаж сам подойдёт и будет атаковать пока цель жива

**Способности:**
- **Q** — Удар (2s кулдаун, 60 радиус)
- **W** — Рывок (5s кулдаун, 150 радиус)
- **E** — Щит (8s кулдаун, +30 HP)
- **R** — Ульта (30s кулдаун, 200 радиус, 50 урона)

**Взаимодействие:**
- **ЛКМ по ресурсу** — добыча
- **ЛКМ по луту** — подбор

### 📱 Для мобильных

**Левый нижний угол:**
- **Виртуальный джойстик** — плавное движение

**Правый нижний угол:**
- **Большая красная кнопка ⚔️** — атака ближайшего врага
- **4 кнопки способностей** — Q/W/E/R с кулдаунами

**Взаимодействие:**
- **Тап по объекту** — выбор/добыча/подбор

## 🎯 Особенности MOBA-стиля

✅ **Плавное движение** — lerp-интерполяция, 60 FPS  
✅ **Move-to-click** — клик по земле = движение  
✅ **Автоатака** — персонаж сам атакует выбранную цель  
✅ **Визуализация пути** — линия от персонажа до точки движения  
✅ **Индикатор радиуса** — круг атаки вокруг персонажа  
✅ **Анимации атак** — slash, projectile, magic эффекты  
✅ **Способности с кулдаунами** — визуальные индикаторы  
✅ **Адаптивное управление** — автоопределение ПК/мобильного

### 3. Инвентарь (вкладка "Инвентарь")
- **Экипировка**: нажмите ⚔️ на оружии/броне для экипировки
- **Снятие**: нажмите "Снять" в слотах экипировки
- **Выброс**: нажмите 🗑️ чтобы выбросить предмет
- **В сейф**: нажмите 🔒 чтобы переместить в сейф (только в хабе)

### 4. Сейф (вкладка "Сейф")
- Доступен только в безопасной зоне (Хаб)
- Предметы в сейфе не теряются при смерти
- Нажмите "Забрать" чтобы вернуть предмет в инвентарь

### 5. Крафт (вкладка "Крафт")
- **Создание предметов**: выберите рецепт и нажмите "Создать"
- **Переработка**: разберите ненужные предметы на ресурсы
- Рецепты автоматически изучены при входе

### 6. Рейд (вкладка "Рейд")
- **Вход в рейд**: нажмите "Войти в рейд" (только из хаба)
- **Экстракция**: используйте портал-камень для безопасного выхода
- **Смерть**: при смерти в рейде теряется весь инвентарь и экипировка

### 7. Чат (вкладка "Чат")
- **Глобальный чат**: сообщения видны всем игрокам
- **Чат зоны**: сообщения видны только в текущей зоне
- **Личные сообщения**: прямые сообщения другим игрокам

### 8. God Mode (вкладка "God")
- Доступен только для аккаунта `god@mmo.local`
- **Создание предметов**: спавните любые предметы в мир
- **Быстрые действия**: создайте портал-камни, зелья, оружие

## 🎮 Типичный игровой цикл

1. **Войдите как Player** (`player@test.local` / `player12345`)
2. **Добудьте ресурсы** во вкладке "Мир" (кликните по зелёным точкам)
3. **Скрафтите портал-камень** во вкладке "Крафт" (нужно 10 Stone + 5 Iron)
4. **Перейдите в рейд** во вкладке "Рейд"
5. **Сражайтесь с NPC** (кликните по красным кругам → "Атаковать")
6. **Соберите лут** (кликните по жёлтым квадратам)
7. **Экстрактируйтесь** с портал-камнем во вкладке "Рейд"
8. **Положите ценные предметы в сейф** во вкладке "Инвентарь" (кнопка 🔒)

## 🧪 Тестирование механик

### Хардкор-смерть
1. Войдите в рейд
2. Сражайтесь с NPC пока не умрёте
3. Весь инвентарь и экипировка выпадут на землю
4. Возродитесь в хабе без предметов

### Парадокс сумки
1. Положите предметы в сейф
2. Умрите в рейде
3. Предметы в сейфе **останутся нетронутыми**
4. Потеряется только инвентарь и экипировка

### Портал-камень
1. Скрафтите портал-камень (10 Stone + 5 Iron)
2. Войдите в рейд
3. Используйте "Экстракция" — портал-камень исчезнет, но вы сохраните весь лут
4. Без портал-камня экстракция невозможна

### PvP (если добавить второго игрока)
- Откройте вторую вкладку браузера
- Войдите как другой игрок
- В рейдовой зоне можно атаковать других игроков
- В хабе PvP отключён

## 🏗 Архитектура

### Frontend (этот проект)
- **React + TypeScript** — UI компоненты
- **Mock Server** — эмуляция серверной логики в браузере
- **Canvas** — рендеринг игрового мира
- **Socket.io Client** — интерфейс для взаимодействия

### Backend (отдельный проект в `/server`)
- **Node.js + TypeScript** — серверная логика
- **PostgreSQL + Prisma** — база данных
- **Redis** — кэширование и таймеры
- **Socket.io** — real-time коммуникация

## 📝 Примечания

- Все данные хранятся в памяти браузера (при перезагрузке теряются)
- Mock сервер эмулирует все основные механики
- Для production использования нужен реальный backend (см. `/server`)
- Респаун ресурсов: 30 секунд
- TTL лута: 10 минут
- Таймер рейда: 15 минут

## 🐛 Известные ограничения

- Нет сохранения между сессиями (mock сервер)
- Нет реального мультиплеера (один игрок в браузере)
- Упрощённая графика (Canvas 2D)
- Нет звуковых эффектов

## 🚀 Следующие шаги

Для полноценного мультиплеера:
1. Запустите backend сервер (`cd server && npm run dev`)
2. Настройте PostgreSQL и Redis
3. Подключите frontend к реальному серверу через Socket.io
4. Добавьте аутентификацию через JWT
