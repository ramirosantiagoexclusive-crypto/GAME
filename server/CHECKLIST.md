## 🚀 Команды для запуска

```bash
# 1. Перейти в директорию сервера
cd server

# 2. Установить зависимости
npm install

# 3. Настроить .env
cp .env.example .env
# Отредактировать .env

# 4. Запустить PostgreSQL и Redis
# (см. READY_TO_LAUNCH.md)

# 5. Инициализировать БД
npx prisma migrate dev --name init
npx prisma generate
npm run prisma:seed

# 6. Запустить сервер
npm run dev
```
